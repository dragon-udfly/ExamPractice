# MATLAB Exam Practice & Digital Image Processing (ExamPractice)

A collection of MATLAB scripts, test routines, and image assets dedicated to practicing digital image processing (DIP) workflows, color channel manipulations, and exam-oriented tasks.

---

## 📂 Repository Structure

```text
ExamPractice/
│
├── src/                      # Source image directory containing raw assets
│   ├── earth.jpg             # Earth texture / sample image
│   ├── graffiti.jpg          # Urban texture / sample image
│   ├── industry.jpg          # Industrial sample image
│   ├── motorcycle.jpg        # Object detection / sample image
│   ├── sand.jpg              # Texture sample image
│   └── stones.jpg            # Texture sample image
│
├── Blue_Channel.jpg          # Processed blue channel extraction output
├── Green_Channel.jpg         # Processed green channel extraction output
├── Red_Channel.jpg           # Processed red channel extraction output
│
├── ExamP1.m                  # Exam practice script 1
├── ExamPractice1.m           # Practice solution script 1
├── ExamPractice2.m           # Practice solution script 2
├── ExamPractice3.m           # Practice solution script 3
└── ExamPractice4.m           # Practice solution script 4
```

## 🚀 Key Topics & Operations Covered
1. Color Channel Decomposition: Splitting color images into their respective Red, Green, and Blue channels (Red_Channel.jpg, Green_Channel.jpg, Blue_Channel.jpg).

2. Image Processing Pipelines: Executing modular filter and transformation tasks using MATLAB scripts (ExamPractice1.m through ExamPractice4.m).

3. Test & Exam Preparation: Hands-on scripts designed for academic examination scenarios involving image manipulation.
